# TASK-2 보드 디자인 개편 — Intent

## 목적

참고 시안의 대시보드형 디자인을 Agent Board 보드 화면에 적용한다. 지금 보드는 열과 작은 카드만 보여 주어서, 전체 진행 상황을 파악하려면 카드를 하나씩 열어야 한다. 개편 후에는 보드 첫 화면만 보고 다음을 알 수 있어야 한다.

- 전체 진행률과 남은 작업량
- 구분(BE·FE·Infra·ML)별 진척
- 막혀 있는 작업과 일정이 밀린 작업
- 각 작업을 어떤 에이전트가 맡고 있고, 지금 돌고 있는지

## 배경

### 참고 시안과 현재 보드 비교

| 영역 | 참고 시안 | 현재 보드 |
| --- | --- | --- |
| 상단 요약 | 큰 숫자 지표 5개: 작업 항목 완료율(85%), 완료/전체 항목(245/288), 진행 전·진행·완료 작업 수 | 없음 |
| 구분별 진척 | BE·FE·Infra·ML마다 색이 다른 진행 막대와 "122/145 완료" | 없음. 카드에 구분 정보도 없음 |
| 필터 | 구분 칩(전체·BE·FE·Infra·ML), 완료 시작일 선택, "최근 7일" 버튼 | 없음 |
| 열 구성 | 진행 전 · 진행 · 이슈 · 완료 4열. 열 제목에 개수 표시, 완료 열은 기준일 이후만 표시 | Todo · In Progress · Review · Suspended · Done 5열 |
| 카드 | 큰 제목, 진행 막대와 "1/6", 구분 태그(색 점), "10-14 시작", 지연 표시(D+24, 빨강), 선행 작업, 에이전트 칩(도구 아이콘·이름·상태 점) | 작업 ID, "7/20" 텍스트, 역할·도구·실행 상태 배지 |
| 시각 스타일 | 어두운 배경, 큰 모서리의 카드, 넉넉한 여백, 큰 글자, 낮은 대비의 보조 텍스트, 구분별 고유 색 | VS Code 기본 위젯 스타일, 촘촘한 배치 |

### 시안을 그대로 옮기려면 필요한 데이터

시안은 지금 카드에 없는 정보를 보여 준다. 디자인만 바꾸면 비어 보이는 영역이 생긴다.

| 시안 요소 | 필요한 데이터 | 현재 |
| --- | --- | --- |
| 구분별 진척, 구분 태그·필터 | 카드의 구분(복수), 체크리스트 항목별 구분 | 없음 |
| "10-14 시작", D+N | 작업 시작일, 기준일(마감일 또는 시작일) | `createdAt`만 있음 |
| 선행 작업 | 카드 간 선행 관계 | 없음 |
| 완료 기준일 필터 | 완료 시각 | 상태 변경 시각을 따로 기록하지 않음 |
| 에이전트 칩 여러 개 | 카드에 연결된 세션 목록과 상태 | 실행 회차 기록이 있어 표시 가능 |
| 이슈 열 | 이슈 상태의 정의 | Review·Suspended와의 관계가 정해지지 않음 |

### 지켜야 할 기존 요구사항

- 라이트·다크·고대비 테마를 따르고 키보드만으로 조작할 수 있어야 한다 (spec N-4). 시안은 다크 테마 기준이므로, 색은 테마 변수를 바탕으로 한 토큰으로 정의하고 다른 테마에서도 읽을 수 있어야 한다.
- 카드 200개 보드를 1초 안에 표시한다 (N-1).
- 칸반 상태 규칙(spec 6절)과 상태 이동 시 실행 제어는 그대로 유지한다.

## 범위

### 포함

- 보드 화면 레이아웃 개편: 상단 요약 지표, 구분별 진척, 필터 영역, 칸반 열, 하단 공용 문서 영역
- 카드 디자인 개편: 진행 막대, 구분 태그, 일정 표시, 선행 작업, 에이전트 칩
- 위 표시에 필요한 카드 데이터 추가와 상세 화면의 편집 UI
- 디자인 토큰(색·간격·모서리·글자 크기) 정의와 테마 대응
- 보드 설정 화면: 구분 관리, 연결할 수 있는 에이전트, 리뷰·실행 옵션, 카드 자동 생성

### 제외

- 카드 상세 화면, 실행 이력 탭의 전면 개편 (이번에는 새 데이터 편집 UI만 추가)
- 팀 단위 통계, 담당자별 집계
- 차트 라이브러리 도입

### 결정 사항

| 항목 | 결정 |
| --- | --- |
| 구분 목록 | 사용자가 정하고 추가한다. BE·FE·Infra·ML은 처음 제공하는 기본값이다. 구분은 plan.md에 쓰는 태그(바꿀 수 없음)와 보드에 보이는 표시 이름(바꿀 수 있음)을 따로 가진다. 이름을 바꿔도 plan.md를 고쳐 쓰지 않는다. |
| 항목별 구분 | plan.md 절 제목 맨 앞에 구분 태그를 붙이고 뒤에 상세 내용을 쓴다. 예: `## [BE] 로그인 API`. 그 절 아래 체크리스트 항목이 그 구분으로 집계된다. 카드의 구분 태그는 plan.md에 나온 구분을 모아 만든다. |
| 열 구성 | 현재 5열(Todo·In Progress·Review·Suspended·Done)을 유지하고 모양만 바꾼다. |
| D+N | 마감일을 넘긴 날수. 카드에 시작일과 마감일을 둔다. |
| 선행 작업 | 같은 보드의 카드끼리만 연결한다. |
| 설정 | 흩어져 있는 설정을 보드의 설정 화면 한 곳에 모은다. 구분 목록, 연결할 수 있는 에이전트, 리뷰·실행 옵션, 카드 자동 생성이 포함된다. |
