# TASK-2 보드 디자인 개편 — Spec

[intent.md](intent.md)의 결정 사항을 요구사항과 완료 조건으로 정리한다. ID 접두어는 DS(디자인), CT(구분), CD(카드 데이터), ST(설정)다.

## 요구사항

### 1. 데이터

**공유 설정 (`board.json`)**

| 필드 | 설명 | 기본값 |
| --- | --- | --- |
| `categories` | 구분 목록. `{ tag, name, color }`의 배열이며 순서가 표시 순서다 | 태그 BE·FE·Infra·ML (표시 이름도 같음) |
| `enabledTools` | 이 보드에서 연결할 수 있는 에이전트 도구 | `claude`·`codex`·`cursor` |
| `settings.defaultAutoReview` | 새 카드의 자동 수정·재리뷰 기본값 | `false` |

- 기존 `settings.maxReviewIterations`·`settings.stopTimeoutSec`는 그대로 쓴다.
- **CD-1** 기존 `board.json`을 열면 스키마 버전 2로 마이그레이션해 위 필드를 기본값으로 채운다. 원본은 `local/backup/`에 보관한다 (S-3).

**카드 (`card.json`)**

| 필드 | 설명 |
| --- | --- |
| `startDate` | 시작일 `YYYY-MM-DD` (선택) |
| `dueDate` | 마감일 `YYYY-MM-DD` (선택) |
| `dependsOn` | 선행 카드 ID 목록 (선택) |
| `doneAt` | Done으로 옮긴 시각. Done에서 나가면 지운다 |

- **CD-2** `doneAt`은 사용자 이동과 자동 Done(K-2) 모두에서 기록한다. `doneAt`이 없는 기존 Done 카드는 `updatedAt`을 완료 시각으로 본다.
- **CD-3** `dependsOn`에는 같은 보드의 다른 카드만 넣을 수 있다. 자기 자신과 순환 관계는 저장하지 않는다. 선행 카드가 삭제되면 목록에서 뺀다.
- **CD-4** 시작일이 마감일보다 늦으면 저장하지 않고 이유를 표시한다.

**이 기기 설정 (VS Code 설정)**

`agentBoard.toolPaths`·`agentBoard.autoCreateCards`·`agentBoard.matcherTool`은 지금처럼 VS Code 설정에 둔다. 설정 화면에서도 같은 값을 읽고 쓴다.

### 2. 항목의 구분

구분은 태그와 표시 이름을 따로 가진다.

| 속성 | 쓰는 곳 | 변경 |
| --- | --- | --- |
| 태그 (`tag`) | plan.md 제목에 적는 식별자. 예: `BE` | 만든 뒤 바꿀 수 없다 |
| 표시 이름 (`name`) | 보드·카드·설정 화면에 보이는 이름. 예: 백엔드 | 언제든 바꿀 수 있고, plan.md는 건드리지 않는다 |

- **CT-0** 태그는 영문자·숫자·`-`·`_`로 1~20자이며, 대소문자 구분 없이 보드 안에서 유일하다. 표시 이름은 1~30자이다.
- **CT-1** plan.md의 제목 줄이 `[태그]`로 시작하면, 그 절은 해당 구분에 속한다. 예: `## [BE] 로그인 API`. 태그는 대소문자를 가리지 않는다.
- **CT-2** 체크리스트 항목의 구분은 가장 가까운 상위 제목에서 정한다. 그 제목에 태그가 없으면 더 상위 제목의 태그를 따른다. 태그가 있는 상위 제목이 없으면 "미분류"다.
- **CT-3** 보드에 없는 태그는 "미분류"로 집계한다. 카드 상세의 Plan 탭에서 알 수 없는 태그를 표시한다.
- **CT-4** 카드의 구분 태그는 plan.md에 나온 구분을 보드 구분 순서로 모은 것이다. 카드에 따로 저장하지 않는다.

### 3. 보드 화면

보드 화면은 위에서부터 요약 지표, 구분별 진척, 필터, 칸반, 공용 문서 순서로 놓는다.

**요약 지표**

- **DS-1** 다섯 가지 지표를 큰 숫자로 보여 준다. 필터의 영향을 받지 않는다.

| 지표 | 계산 |
| --- | --- |
| 작업 항목 완료율 | 전체 카드의 완료 항목 수 ÷ 전체 항목 수. 항목이 없으면 `—` |
| 완료 / 전체 항목 | 위의 두 수 |
| 진행 전 작업 | Todo 카드 수 |
| 진행 작업 | In Progress + Review 카드 수 |
| 완료 작업 | Done 카드 수 |

**구분별 진척**

- **DS-2** 항목이 하나 이상 있는 구분마다 "표시 이름 + 완료/전체 + 구분 색의 진행 막대"를 보여 준다. 미분류 항목이 있으면 마지막 줄에 "미분류"를 둔다.

**필터**

- **DS-3** 구분 칩을 둔다. 칩은 "전체"와 각 구분이며 하나만 선택된다. 선택한 구분이 카드의 구분 태그에 있는 카드만 칸반에 보인다.
- **DS-4** Done 열에는 완료 시작일 필터를 둔다.
  - 날짜를 고르면 `doneAt`이 그 날짜 이후인 카드만 보인다.
  - "최근 7일" 버튼은 오늘 포함 7일 전 날짜를 고른다.
  - 날짜를 비우면 전부 보인다.
  - 열 제목은 "Done · MM-DD 이후 · 개수"로 표시한다.
- **DS-5** 필터 선택은 보는 사람의 화면 상태로만 기억한다. 공유 파일에 쓰지 않는다.

**칸반과 카드**

- **DS-6** 열은 현재 5열(Todo·In Progress·Review·Suspended·Done)을 유지한다. 열 제목에 필터 적용 후 개수를 표시한다. 드래그·키보드 이동 규칙은 바꾸지 않는다.
- **DS-7** 카드에는 위에서부터 다음을 보여 준다.
  1. 제목 (크게), 작업 ID (작게)
  2. 진행 막대와 `완료/전체`. 항목이 없으면 막대 없이 `—`
  3. 구분 태그 (구분 색 점 + 표시 이름)
  4. 일정: 시작일이 있으면 "MM-DD 시작". 마감일을 넘겼으면 빨간색 `D+N`을 붙인다. 넘기지 않았으면 "MM-DD 마감"을 흐리게 표시한다.
  5. 선행 작업: "선행: 카드 제목". 선행 카드가 Done이 아니면 경고 색으로 표시한다.
  6. 에이전트 칩
  7. 기존 배지 (재리뷰 필요, ID 중복, 수동 완료, worktree 없음)
- **DS-8** D+N은 다음과 같이 계산한다.
  - Done이 아닌 카드: 오늘 − 마감일
  - Done 카드: 완료일 − 마감일
  - 0 이하면 표시하지 않는다. 날짜는 이 기기의 시간대 기준이다.
- **DS-9** 에이전트 칩은 카드에 연결된 세션마다 하나씩 보여 준다.
  - 칩 내용: 도구 아이콘, 도구 이름, 상태 점
  - 상태 점 색: 실행 중=초록, 입력 필요·중단 중=노랑, 오류·상태 확인 필요=빨강, 그 외=회색
  - 칩은 3개까지 보이고 나머지는 `+N`으로 표시한다.
  - 칩을 누르면 그 세션을 연다(프로젝트 spec B-6).
- **DS-10** 선행 작업을 누르면 그 카드의 상세 화면을 연다.

**시각 스타일**

- **DS-11** 색·간격·모서리·글자 크기는 디자인 토큰(CSS 변수)으로 정의한다. 기본 색은 VS Code 테마 변수에서 가져와 라이트·다크·고대비 테마를 모두 따른다 (N-4).
- **DS-12** 구분 색은 8색 팔레트에서 고른다. 각 색은 라이트·다크 테마 모두에서 배경 대비 3:1 이상이다.
- **DS-13** 카드는 큰 모서리(12px)와 얇은 테두리를 쓴다. 보조 텍스트는 `descriptionForeground`를 쓴다.
- **DS-14** 화면 폭이 좁으면 요약 지표는 줄을 바꾸고, 칸반은 가로로 스크롤된다.

### 4. 카드 상세

- **DS-15** 개요 탭에서 시작일·마감일(날짜 입력)과 선행 카드(같은 보드 카드 목록에서 선택)를 편집한다. 구분 태그는 읽기 전용으로 보여 주고, plan.md 제목으로 정한다고 안내한다.
- **DS-16** 담당 에이전트 선택 목록에는 `enabledTools`에 있는 도구만 나온다. 이미 지정된 도구가 꺼져 있으면 "사용 안 함"으로 표시하고 실행 버튼을 비활성화한다.

### 5. 설정 화면

- **ST-1** 보드 상단의 설정 버튼이나 명령 **Agent Board: 설정 열기**로 보드 안의 설정 화면을 연다. 각 항목에 "팀 공유"(board.json) 또는 "이 기기"(VS Code 설정)를 표시한다.
- **ST-2** 구분 (팀 공유)
  - 추가할 때 태그·표시 이름·색을 정한다. 태그와 이름은 CT-0 규칙으로 검증한다.
  - 추가한 뒤에는 표시 이름·색·순서만 바꿀 수 있다. 태그 입력란은 읽기 전용으로 두고, plan.md 제목에 쓰는 값이라고 안내한다.
  - 구분마다 plan.md에 쓸 예시(`## [BE] 제목`)를 보여 주고 복사할 수 있게 한다.
- **ST-3** 구분을 삭제하면, 그 태그를 쓰는 항목 수를 보여 주고 "미분류가 된다"는 확인을 받는다. plan.md는 바꾸지 않는다. 같은 태그로 다시 추가하면 해당 항목은 그 구분으로 다시 집계된다.
- **ST-4** 에이전트
  - 도구마다 다음을 보여 준다: 이 보드에서 사용 여부(팀 공유, `enabledTools`), 설치 여부와 버전, CLI 경로 지정(이 기기), Hook 설치 여부와 설치 버튼(이 기기).
  - "다시 찾기"로 CLI를 다시 확인한다.
- **ST-5** 리뷰·실행 (팀 공유)
  - 자동 수정·재리뷰 최대 반복 횟수: 1~10
  - 중단 대기 시간(초): 2~120
  - 새 카드의 자동 수정·재리뷰 기본값
- **ST-6** 카드 자동 생성 (이 기기): 자동 생성 켜기·끄기, 판단에 쓸 CLI를 설정한다.
- **ST-7** 값은 바꾸는 즉시 저장한다. 잘못된 값은 저장하지 않고 입력란 옆에 이유를 표시한다.
- **ST-8** board.json에 병합 충돌이 있으면 팀 공유 항목을 읽기 전용으로 두고 이유를 표시한다 (S-7).
- **ST-9** 꺼진 도구는 자동 생성의 판단 CLI와 새 카드의 구현자로 쓰지 않는다.

### 6. 비기능

- **DS-17** 카드 200개 보드에서 지표 계산을 포함해 1초 안에 표시한다 (N-1).
- **DS-18** 필터 칩, 날짜 입력, 설정 화면의 모든 조작을 키보드로 할 수 있다 (N-4).

## 완료 조건

- [x] plan.md에 `## [BE] …`, `## [FE] …` 절이 있는 카드들로 요약 지표와 구분별 진척이 올바르게 계산된다. 미분류 항목은 "미분류" 줄에 집계된다.
- [x] 구분 칩으로 고른 구분의 카드만 칸반에 보이고, "최근 7일"을 누르면 Done 열에 최근 7일 안에 완료된 카드만 보인다.
- [x] 마감일이 지난 진행 중 카드에 빨간 `D+N`이 표시되고, N이 오늘 − 마감일과 같다.
- [x] 선행 카드가 Done이 아니면 경고 색으로 표시되고, 누르면 그 카드가 열린다. 순환 관계는 저장되지 않는다.
- [x] 설정 화면에서 구분을 추가하면 그 태그를 쓴 plan.md 항목이 집계되고, 표시 이름을 바꾸면 보드 표시만 바뀌며 plan.md는 그대로다.
- [x] 구분을 삭제하면 해당 항목이 미분류로 집계되고, 같은 태그로 다시 추가하면 원래대로 집계된다.
- [x] 도구를 끄면 담당 에이전트 선택 목록과 판단 CLI에서 빠진다.
- [x] 라이트·다크·고대비 테마에서 모든 텍스트와 구분 색을 읽을 수 있다.
- [x] 카드 200개 보드가 1초 안에 표시된다.
- [x] 기존 board.json(스키마 1)을 열면 기본 구분과 도구 목록이 채워지고 원본이 백업된다.
